# Proficiency validation

Controlled vocabulary and syntactic-range rewrites of untreated LURK Werewolf speech.
The workflow uses automated fidelity checks, linguistic measurements and blind model
ratings. [VALIDATION.md](VALIDATION.md) contains the current pilot results.

## Structure

The two entry points are `python -m experiments.proficiency_validation.rewrite` and
`python -m experiments.proficiency_validation.validation`.

| Path | Contents |
| --- | --- |
| `rewrite/` | Generation, English fidelity checks, model transport and artifact storage |
| `validation/` | Source preparation, measurements, model ratings, calibration, protocol and analysis |
| `data/corpus/` | Untreated source records, baseline passages and features, corpus manifest |
| `data/runs/<run>/rewrite/` | One canonical rewrite artifact containing all attempts and outcomes |
| `data/runs/<run>/validation/` | Passage selection, measurements, model responses and the combined JSON report |
| `data/runs/<run>/manifest.json` | Model declarations, checkpoints, QC, provenance and verified shard receipts |
| `tests/` | Offline regression tests |

The reusable prompt implementation is
[`components/rewriters/language_rewriter.py`](../../components/rewriters/language_rewriter.py).
Runtime integration uses `rewrite.gate.GatedRewriter`.

The corpus contains 280 untreated utterances from three games generated by
`deepseek-chat`. Raw game logs are kept locally in `experiments/validation/`,
which Git ignores. Curated records contain the inputs needed for offline reporting.
The archived Qwen3.5-27B run is `data/runs/pilot_qwen35_27b/`.

Each run has one manifest. Checkpoints preserve settings and recorded failures.
Changed source data, model identities or generation settings require a new run.
Parallel generation reads disjoint rows from the canonical source file. After a
verified merge, the original shard bytes occur once in `rewrite/rewrites.jsonl`;
byte ranges, hashes and settings in the manifest preserve their audit trail.
An interrupted job retains its partial output until it resumes or is explicitly discarded.

## Setup

Run commands from the repository root. Dependencies are declared in `pyproject.toml`.

```bash
pip install -e '.[proficiency]'
python -m spacy download en_core_web_sm
```

Set `PROFICIENCY_MODEL_CONFIG` to the run's `manifest.json`. Its `models` mapping
declares each handle's model, family, endpoint environment variable, weight revision,
tokenizer revision and serving settings. The local scripts in `hpc/` initialize
these declarations before starting workers. Generation and rating commands use the
configured local model service. Reporting uses stored artifacts and makes no model requests.

## Reproduce the current report

```bash
python -m experiments.proficiency_validation.validation report \
    --pilot-dir experiments/proficiency_validation/data/runs/pilot_qwen35_27b \
    --out experiments/proficiency_validation/VALIDATION.md \
    --json experiments/proficiency_validation/data/runs/pilot_qwen35_27b/validation/report.json
python -m experiments.proficiency_validation.rewrite verify-run \
    --rewrites experiments/proficiency_validation/data/runs/pilot_qwen35_27b/rewrite/rewrites.jsonl
python -m unittest discover -s experiments/proficiency_validation/tests
```

The report includes the source audit, construction failures, passage coverage,
measured contrasts and auxiliary CEFR results. Missing evidence remains missing.
To rebuild the corpus from local untreated logs, use `validation prepare-data`
with the game directories. `rewrite generate --dry-run` prints prompts without
contacting a model.

## Pilot workflow

Use a new run directory when changing the generation policy. The model handles below
refer to declarations in that run's manifest.

```bash
PROFICIENCY_RUN=experiments/proficiency_validation/data/runs/pilot_next
PROFICIENCY_SOURCES=experiments/proficiency_validation/data/corpus/sources.jsonl
export PROFICIENCY_MODEL_CONFIG="$PROFICIENCY_RUN/manifest.json"

python -m experiments.proficiency_validation.rewrite generate \
    --sources "$PROFICIENCY_SOURCES" --conditions low,neutral \
    --generator generator --judge judge --judge-max-tokens 3072 \
    --neutral-edit-tolerance 0.10 --out "$PROFICIENCY_RUN/rewrite/rewrites.jsonl"
python -m experiments.proficiency_validation.validation bundles \
    --sources "$PROFICIENCY_SOURCES" --selection whole_game --window 150 250 \
    --out "$PROFICIENCY_RUN/validation/bundles.jsonl"
python -m experiments.proficiency_validation.validation features \
    --bundles "$PROFICIENCY_RUN/validation/bundles.jsonl" \
    --rewrites "$PROFICIENCY_RUN/rewrite/rewrites.jsonl" --conditions original,low,neutral \
    --out "$PROFICIENCY_RUN/validation/features.jsonl"
python -m experiments.proficiency_validation.validation probe \
    --assembled "$PROFICIENCY_RUN/validation/features_assembled.jsonl" \
    --listeners listener_qwen --pairs low:neutral,neutral:original --construct range \
    --max-tokens 768 --out "$PROFICIENCY_RUN/validation/listener.jsonl"
python -m experiments.proficiency_validation.validation probe \
    --assembled "$PROFICIENCY_RUN/validation/features_assembled.jsonl" \
    --listeners listener_qwen --pairs low:neutral,neutral:original --construct perceived_proficiency \
    --max-tokens 768 --out "$PROFICIENCY_RUN/validation/listener_proficiency.jsonl"
python -m experiments.proficiency_validation.validation cefr-rate \
    --bundles "$PROFICIENCY_RUN/validation/bundles.jsonl" \
    --rewrites "$PROFICIENCY_RUN/rewrite/rewrites.jsonl" --raters listener_qwen \
    --max-tokens 1536 --out "$PROFICIENCY_RUN/validation/cefr.jsonl"
python -m experiments.proficiency_validation.validation report \
    --pilot-dir "$PROFICIENCY_RUN" --out experiments/proficiency_validation/VALIDATION.md \
    --json "$PROFICIENCY_RUN/validation/report.json"
```

`features --subtlex PATH` supplies lexical-frequency norms. `guardrails` measures
grammar and acceptability on the assembled passages using LanguageTool and CoLA.
Unavailable instruments leave missing measurements. Each command lists its
instrument arguments under `--help`.

`build-challenge`, `run-challenge` and `report-challenge` provide automated fidelity
diagnostics. `cefr-calibrate` evaluates existing externally labelled learner-production
samples. Store calibration inputs and results under the run's `validation/calibration/`.
These tools are subcommands of the validation entry point.

For distributed generation, pass `--shard-index` and `--shard-count` to `rewrite generate`
and write temporary outputs below `rewrite/shards/`. `rewrite merge-rewrites` verifies
the complete source-condition grid and a common generation policy before compaction.
`--resume` preserves outcomes under the recorded settings, including failures.

`freeze` and `verify-frozen` record the confirmatory decisions described below.
The default protocol path is `data/protocol/frozen_config.json`. Formal commands
use the same `--frozen` file and `--split`. `analyze` evaluates formal criteria or
selected exploratory artifacts; `report` combines the source and pilot results.

## Construct and conditions

The manipulation changes vocabulary familiarity, lexical diversity and syntactic
range. Low uses simpler language while preserving grammaticality and comprehensibility.
High expands linguistic range while preserving evidence, certainty, persuasive force
and interpersonal register. Low uses naturally connected clauses and preserves
causal and conditional links. Mechanical fragmentation is not a treatment objective.

| Condition | Role | Intended realization |
| --- | --- | --- |
| Original | Untreated baseline | The original Stage-2 game speech |
| Neutral | Paraphrase control | New wording with the original range and pragmatic force |
| Low | Primary treatment | More familiar and repetitive vocabulary, simpler syntactic choices |
| High | Separate extension | Less restricted vocabulary and syntax under the same fidelity contract |

Low versus Neutral is the main comparison. Neutral versus Original checks the
paraphrase control. A High extension has a separate Neutral control matched to High,
its own frozen design and independent confirmation. Low versus Original is descriptive.

Matching edit distance reduces differences in the amount of surface change.
Fidelity checks and equivalence tests assess other properties of the rewrite.
Neutral preserves repeated word choices and construction patterns. Local wording
changes cannot systematically increase lexical variety or syntactic embedding.
Candidate selection first requires fidelity and Neutral-range checks, then matches
edit distance among candidates that pass. A candidate outside the declared absolute
distance tolerance is unavailable even when its meaning is preserved. The target
and tolerance are included in candidate-generation instructions with the word-token
distance definition and an approximate edit count. Retries receive the measured
distance, direction of adjustment and previous candidates. The closest candidate
with a passing fidelity verdict is retained across attempts. Paired edit-distance
means and per-pair gaps use the same accepted treatment and control cohort. Anchor
distances for attempted but unavailable controls describe selection by edit intensity.
The pilot default tolerance of 0.10 is a development setting requiring empirical
justification before freezing. Aggregate equivalence is evaluated on
fresh games under the prespecified bounds.
Word count, sentence count and edit distance are reported as diagnostics; matching
alone provides limited control over differences between conditions.

## Sources and sampling

Sources are untreated public speech from game logs. All public speech-act types
are eligible, including role claims and divine-result claims.

The source corpus contains all 280 utterances from run01, run02 and run03.
The manifests reuse an internal game ID, so directory names identify source games.
Exact repeated wording is reported. Actual hidden roles are not supplied to
rewriters or judges.

The primary passage contains all of one speaker's ordered utterances from one game.
Each condition uses identical source IDs selected from Original before rewriting.
Speakers below the prespecified minimum original word count are ineligible.
Missing rewrites make a passage incomplete. Its successful utterances are not
concatenated into a shorter substitute.

A length-controlled sensitivity analysis samples whole utterances from the early,
middle and late thirds of each speaker's chronological sequence. The implementation
names this rule `phase_stratified`; strata are chronological thirds, not engine
phase labels. Seeded sampling proceeds across thirds and restores speech order.
A sample that fails to represent every nonempty third is ineligible under this rule.
The source IDs and word window are fixed before rewriting. The archived pilot also
contains 150 to 250 word prefix passages for comparison.

Whole transcripts reduce dependence on a single utterance but vary with survival,
role and speaking opportunities. Word counts, eligibility and missingness are
reported alongside both passage analyses. MATTR and MTLD reduce some length effects;
their interpretation still depends on task and sample length. See
[Kyle et al.](https://doi.org/10.1017/S0272263123000402).

The game is the independent sampling unit. Speakers receive equal weight within
a game, and games receive equal weight. Passage windows, per-game caps and eligibility
rules are specified before confirmatory rewriting. A fixed minimum word count is
a study decision requiring justification, not a universal proficiency threshold.

Pilot, Set A and Set B must use disjoint games. The three source runs are for
development and source auditing. Automatic judge diagnostics can be run on the
pilot, but confirmatory evidence must come from fresh games after the protocol is frozen.

## Generation and fidelity

The validation workflow uses GatedRewriter or the generate command to apply
the English fidelity gate to each candidate rewrite.

The treatment is generated and gated first. Neutral candidates are checked under
the same gate and matched to the exact accepted treatment's distance from Original.
For the main study the anchor is Low. The High extension uses High. A failed anchor
makes Neutral unavailable and remains visible in the attempt log. Anchor-blocked
outcomes are distinguished from failures of attempted Neutral rewrites.

Candidate verdicts are reused only for exact text repeats within the same source
and generation call. Missing verdicts remain eligible for rejudging. Full candidate
checks and verdict reuse are recorded in the attempt log. A retained candidate
must still satisfy the distance tolerance to become an accepted control.

Offline generation and checkpoint resume reuse the recorded accepted anchor.
Runtime Neutral generates a local gated anchor when none is supplied. That anchor
defines its matching policy; it is not guaranteed to equal a rewrite generated in
another branch. Exact paired stimuli therefore use the offline accepted rows.
Interactive branches with different histories cannot share an anchor solely because
their turn IDs match.

Every candidate must preserve the predicate, target, reasons, stance, references,
speaker perspective, politeness and interpersonal register. The register check concerns
social stance, respect and interpersonal tone. Simpler vocabulary or shorter clauses
alone do not establish a register violation. The rubric retains strict checks on
reasons, evidential links and certainty.

The English judge returns quoted alignments of the propositions in both texts.
The software verifies that the excerpts occur in the supplied texts and cover every
word. An incomplete answer receives one evidence-repair request for the same texts,
with the uncovered words and original character offsets. Both responses are retained.
Unresolved missing evidence, ungrounded quotations or inconsistent flags produce no
verdict and stop regeneration for that candidate. A non-equivalent alignment or a
grounded structured violation prevents acceptance even if the global dimension
flags are true. An explicit negative judgment is retained without a repair request.
Quote coverage checks the completeness of the response format;
semantic equivalence remains a model judgment subject to calibration.

Proficiency surface checks preserve explicit courtesy markers. Lexical action-slot
matches and paraphrased stance markers are passed to the semantic judge for
adjudication. An unresolved signal cannot pass without a complete semantic verdict.
The collaborator's shared structural checker and inverse parser are used without
modification.

The inverse parser sees only prior public history. If the utterance's location
cannot be established, generation stops to prevent future-context leakage.
Original is parsed under the same input restrictions, and its result is cached for
the source. A discrepancy between Original and its supplied predicate is recorded
separately. When both texts recover the same secondary act, their content slots
and the full English semantic check must agree. Unrecoverable parser output is a
missing judgment. Parser agreement on one act does not establish preservation of
the other propositions in the utterance.
When single-label comparisons disagree, a separate blind extraction lists all
supported acts in each text with their arguments and grounded quotations. Its input
contains the text, speaker, phase and prior history. The expected predicate is not
provided. Both extractions must be complete and their entire act inventories must
match. This comparison also requires the full English semantic verdict.
An absent or malformed judge answer never becomes a pass. Corrective retries use
actual fidelity failures as feedback; infrastructure errors are recorded separately.
Model-output failures, unchanged candidates, matching failures and anchor failures
have distinct diagnostic counts. Archived status labels remain intact.
Retry budgets and completion limits are frozen after development. HTTP failures
record the status, response excerpt, prompt hash and character counts. A permanent
request error stops transport retries, rejudging and corrective regeneration for
that source. Character counts are diagnostics and are not token counts. Context
truncation requires an explicit policy that preserves referenced evidence.

Sentence-boundary changes are valid syntactic edits. Copy detection ignores
whitespace and capitalization while preserving punctuation differences, allowing
clause splitting to count as a syntactic change.

## Automated evidence and interpretation

Validation uses automated linguistic measurements and model judgments. Linguistic
features measure the intended range changes, and grammar instruments assess
correctness. The inverse parser and English model judge assess fidelity. Blind
model listeners test whether the range difference affects model perception.

Synthetic perturbations can diagnose the fidelity checks during development.
Identity controls and preserved simplifications test false rejection, while targeted
changes test detection of altered attribution, roles, numerical qualifications,
courtesy, certainty and reasons. Fixed minimal pairs are development regressions,
including examples represented in the rubric. Their performance is not held-out
judge accuracy. Results are separated by challenge type. Their diagnostic value depends on the
constructed labels being correct. Challenge-set sensitivity describes detection
on these constructed cases. Accuracy on naturally generated rewrites remains
an external-validity limitation of this diagnostic.

Claims concern measured linguistic range and model perception. Generalization to
human judgments of naturalness, human perception or overall English ability requires
separate evidence. Agreement across listener families remains subject to correlated
model errors.

## Measures and criteria

| Evidence | Frozen criterion |
| --- | --- |
| Lexical familiarity | Low raises SUBTLEX mean relative to Neutral; High reverses the direction |
| Lexical diversity | Low reduces MATTR relative to Neutral; High reverses the direction |
| Syntax | Low reduces subordinate clauses per 100 words; High reverses the direction |
| Grammar and acceptability | Each treatment is equivalent to Neutral under justified raw-unit margins, with acceptable absolute observed quality |
| Paraphrase control | Neutral is equivalent to Original on primary range measures and model perception |
| Automated fidelity | Accepted rewrites pass structural, inverse-parser and English semantic checks under the frozen generation policy |
| Perception | Every declared model listener exceeds the prespecified meaningful separation in the predicted direction |
| Availability | Both treatment and Neutral meet the minimum acceptance rate and maximum differential attrition |

SUBTLEX mean, MATTR and subordinate clauses per 100 words are the default primary
metrics. Alternatives must be chosen before confirmation and cover familiarity,
diversity and syntax. Custom clause-pattern entropy and distinct-ratio measures
remain exploratory. Lexical definitions pin the SUBTLEX column, file hash,
domain-word treatment, MATTR window and spaCy versions. Insufficient coverage
prevents confirmation. Sentence count, mean sentence length and subordinate clauses
per sentence remain diagnostics because sentence splitting can mechanically change them.

The range-perception indicator is the game-weighted probability that a listener
selects the treatment as showing more limited vocabulary and sentence range. A
separate perceived-proficiency probe asks which speaker appears to have a weaker
command of English across the transcript. It measures an impression from the
displayed sample. Each construct uses its own prompt and output records; their
votes are analyzed separately. A claim about perceived proficiency requires the
`perceived_proficiency` construct in the frozen design and its own completed
comparisons. Both constructs use the declared listener separation and equivalence
margins, whose rationale must cover the declared constructs.

Each indicator is reported for each listener with an interval and both presentation
orders. Linguistic measures and
quality checks establish what this probability represents. They are not combined
into an arbitrarily weighted proficiency score.

An entire speaker-game transcript is still a task-specific language sample.
It does not establish an overall CEFR level. Resources such as UniversalCEFR include
multiple educational and learner-text tasks whose labels require task-specific
interpretation. The auxiliary CEFR measure uses an
explicit sample-production rubric adapted from the Council of Europe's
[CEFR Companion Volume](https://rm.coe.int/common-european-framework-of-reference-for-languages-learning-teaching/16809ea0d4).
The rubric uses broad bands A, B and C, covering Basic User, Independent User and
Proficient User. A fixed prompt asks the model to judge the band directly.
It describes the language demonstrated in a speaker-game sample. It does not
measure reading difficulty or certify the speaker's overall ability.

Each prespecified whole-game speaker passage is rated independently. Turn boundaries
and chronology are preserved. Raters receive one text condition at a time without
condition labels, expected bands or paired alternatives. The rating includes an
ordinal A/B/C band and exact evidence for linguistic range, grammatical control
and coherence. Insufficient evidence and invalid responses remain missing. Ratings
never determine rewrite acceptance, regeneration or passage eligibility.
Low has no prescribed band. Accurate basic language can receive A; grammatical
errors are not a requirement for A or B. Without external calibration, pilot results
are reported as exploratory CEFR-referenced broad-band LLM ratings. They do not
establish validated CEFR classifications.

Calibration uses existing externally labelled learner-production samples with
dataset provenance. Reference labels A1/A2 map to A, B1/B2 to B and C1/C2 to C.
Original reference labels remain recorded. Reading-difficulty labels are ineligible. Prompt examples and
calibration items are disjoint, and their texts are checked against the experimental
samples. Development choices must be fixed before a separate held-out calibration
set is used for the final accuracy estimate. Automated calibration reports exact
band agreement on all items, valid-response rate and a three-band confusion
matrix. Missing responses count against exact agreement. Calibration does not
establish transfer validity from learner writing to game dialogue. Research on
[automatic CEFR assessment](https://aclanthology.org/2023.bea-1.49/) motivates checking
this measurement empirically; [UniversalCEFR](https://aclanthology.org/2025.emnlp-main.491/)
illustrates why the source task must be identified.

The frozen auxiliary protocol identifies raters, model revisions, rubric and example
hashes, the calibration artifact and justified minimum calibration criteria. Rater
families differ from the generator family. All three reference bands must have the
declared calibration coverage. An additional rater can measure sensitivity to model
choice; results remain separate by rater.

Report band distributions, ordinal transition tables and the proportions of paired
samples rated lower, equal or higher. Speakers receive equal weight within games
and games receive equal weight. Intervals resample games and retain the small-sample
limitations of the main analysis. No mean of numerical band codes is computed.
Report all eligible samples and missing ratings in the denominators. A same-band
rating can conceal a change within a band and does not establish Neutral equivalence.
Auxiliary score direction does not
enter the primary manipulation criteria; a declared auxiliary measurement still
requires complete records and valid provenance.

LanguageTool grammar counts use the versioned category and rule mapping, including
the explicit article-agreement override. Usage, spelling, punctuation and style
are recorded separately. CoLA provides model-based acceptability estimates. The
acceptable-label index, checkpoint and sentence segmentation are recorded and
verified. Overlong sentences produce an explicit failure. Interpretation of these
instruments is limited to their operational measures of grammar and acceptability.

At least three distinct listener families are required for confirmation. They
must differ from the generator and fidelity-judge families. The semantic judge must also use a different
family from the generator. The generator must differ from
the declared behavioral-agent families. Qwen3.5 is the planned first test family;
the exact checkpoint and its role are recorded for each run. Development
tests can use Qwen alone; confirmation requires the full set of declared families.

Model probes use both presentation orders. Both outcomes are recorded even when
one request fails; directional inference uses complete counterbalanced comparisons.
The report records how often the same condition is selected across both orders and
how often the listener always chooses position A or B. A pooled proportion near
one half does not establish order stability or control equivalence.
The effect must hold for each listener and in both orders. For Low, the entire
95% interval must exceed 0.5 plus the frozen minimum meaningful separation. For
High, it must lie below 0.5 minus that separation. The separation and its scientific
rationale are specified before confirmation.

## Statistics and research decisions

Compute paired differences within passages, average speakers within each game and
resample these game means for uncertainty. Standardized paired effects use the
mean and standard deviation of game differences. Bundle-level standardized effects
are descriptive. The frozen
protocol records bootstrap draws, sign-flip repetitions and the random seed.
For up to twelve games, the sign-flip test enumerates all sign assignments. Larger
cohorts use Monte Carlo signs. The method, number of patterns and minimum attainable
two-sided p-value are reported. With three games the minimum is 0.25, so that design
cannot establish a difference at the 0.05 level with this test.
Sign-flip inference assumes game-level symmetry under the null. Bootstrap
sampling procedures depend on the number of independent games for reliable uncertainty
estimation.

Range confirmation requires the expected direction, a 95% interval excluding zero,
BH-adjusted significance and the declared minimum paired standardized effect.
The range-test family contains the designated primary metrics for the study's
single treatment contrast. High has a separate study and correction family.
Nuisance metrics are excluded. All designated primary metrics must
pass; exploratory findings do not substitute for a missing primary result.

Grammar and Neutral-control equivalence require the entire 90% paired-difference
interval to lie within justified raw-unit bounds. A degenerate bootstrap distribution
does not establish equivalence. Neutral-versus-Original perception requires its
90% interval to lie entirely inside the frozen band around 0.5 in both orders.
An interval merely covering 0.5 is insufficient.

Listener intervals resample games. If observed game data yield a zero-width
proportion interval, a conservative bounded-mean Hoeffding interval is used.
With fewer than two games the interval is unavailable. Wilson response-level
intervals and raw-vote Bradley–Terry results are descriptive supplements with a
different weighting from the primary game-weighted probability.

Equivalence bounds represent the largest scientifically negligible difference.
The scientific rationale determines each bound before confirmation. Pilot variation
informs prospective power calculations. Absolute-quality cutoffs have separate
justifications.

Choose sample sizes using the full joint decision rule, including equivalence,
both presentation orders, unavailable rewrites and game clustering.
Archive the power calculation and its assumptions with the study rationale. The
software checks the declared sample minima. Observed quality pass rates and absolute
means serve as sample-level screening rules, with population generalization requiring
additional uncertainty assessment. The availability minimum and the maximum absolute
acceptance-rate difference between treatment and Neutral require a recorded rationale.
QC reports acceptance and failures by predicate, phase and game, including the
composition of retained and excluded sources. Set B independently repeats the full protocol.
Complete-passage retention has a separate denominator based on eligible Original
transcripts. The report includes the original lengths, utterance counts and game
composition of retained and excluded passages. Shorter retained transcripts limit
the population described by the successful-pair analysis.

## Freezing and provenance

Freeze the automated protocol after the pilot. Required decisions
include conditions, primary metrics, equivalence bounds and rationales, effect
thresholds, sample minima, coverage limits, edit-distance tolerances,
measurement versions, model identities, completion budgets and statistical settings.

The freeze also stores complete preselected bundle records, source-file hashes and
disjoint splits. It hashes prompts, the English rubric, measurement code, inference
code and protocol checks. Formal commands pin settings from this artifact and stop
when code or declared models differ. Every empirical threshold is specified in the
protocol. Schema 6 records the automated scope, game-weighted estimand, single
treatment anchor, passage selection, declared perception constructs, meaningful
perception separation and whether auxiliary CEFR measurement is enabled. Protocol freezing is
scheduled after the pilot.

Model revisions and serving metadata must be recorded for Qwen3.5 and any later
DeepSeek checkpoint. Archive the actual model artifacts and execution environment
alongside model declarations to document the weights used by each server.

## Behavioral experiments and missing treatments

For a fixed-stimulus experiment, all eligibility decisions can be completed before
behavioral outcomes are collected. Retain construction failures and document the
population to which the resulting stimulus set applies.

For an interactive game, future speech and rewrite failures occur after assignment.
The primary behavioral analysis must retain every assigned branch, including
fallbacks. It estimates the effect of the declared rewriting policy. Excluding
branches because a later rewrite or manipulation check failed would condition
on a treatment-dependent event.

GatedRewriter raises on unavailable treatment by default. Continuing with Original
requires an explicit fallback policy and a persistent attempt log with game, branch
and source identifiers. Report fallback frequency and actual delivered exposure.
Use separate logs for separate branches and include stopped games in the
assigned-sample accounting.

Validate actual gameplay exposure as well as long offline passages. Interactive
trajectories form a separate cohort from the preselected Set A and Set B sources.
Their measurement and outcome analysis follow a separate prespecified protocol.
Linguistic validation establishes the operational manipulation; behavioral causal
effects and broader proficiency claims require their own evidence.
